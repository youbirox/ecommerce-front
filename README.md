# Ecommerce Frontend 🛍️

A modern frontend for an e-commerce application built with React, TypeScript, Vite, Tailwind CSS, Redux Toolkit, and React Router.

This project communicates with a Spring Boot REST API to provide authentication, product management, shopping cart, and order management features.

---

## 🚀 Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Redux Toolkit
* React Router
* Axios

## 🛠️ Installation

Clone the repository:

```bash
git clone https://github.com/youbirox/ecommerce-front.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

---

## 🔗 Backend API

This frontend is designed to work with the Spring Boot backend available in the **ecommerce-api** repository.

Default API URL:

```text
http://localhost:8080
```
